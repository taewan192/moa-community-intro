## 광장과 채널

광장은 상위 채널별 인기글을 최대 10개씩 보여 줍니다. 세부 채널, 제목, 추천 수, 조회 수, 댓글 수를 함께 확인할 수 있습니다. 운영자가 수동 블라인드한 글과 자동 블라인드 조건을 만족한 글은 공개 인기글에서 제외됩니다.

상위 채널은 **운영 방침 및 법령 → 게임 → 애니 & 만화 → 일상 → 유머 → 영화 → 테크** 순서로 구성됩니다. 일반 콘텐츠 채널의 '일반' 세부 채널은 앞쪽에 표시합니다. 채널에서는 전체 글을 보고 세부 채널을 선택하면 해당 주제의 글만 봅니다. 게임의 GTA, 애니 & 만화의 애니·만화·소설·그림처럼 주제를 더 나눌 수 있습니다.

전체 채널 보기와 검색, 세부 채널 즐겨찾기를 지원합니다. 세부 채널 신청은 로그인 후 상위 채널과 개설 이유를 제출하는 방식입니다. 일반 회원은 1분 간격, 승인 대기 최대 3건의 제한을 받으며 총괄운영자는 즉시 개설할 수 있습니다. 운영 방침 및 법령의 개설 관련 기능은 총괄운영자에게 제한됩니다.

## 글쓰기와 편집

| 기능 | 동작 |
| --- | --- |
| 작성 | 로그인한 회원이 권한과 이용 제한 검사를 거쳐 작성합니다. 글은 회원별 60초 간격입니다. |
| 수정 | 본인 게시글·댓글을 수정할 수 있고 수정됨 표시가 남습니다. 운영·시스템 글은 별도 권한을 적용합니다. |
| 글자 서식 | 10~32px의 정수 크기와 36·40·48·56·64·72px, 굵게·기울임·밑줄, 제공되는 글자 색, HTTP/HTTPS 링크를 지원합니다. |
| 목록 | 글머리표 목록을 만들고 접기 안에도 목록과 글자 서식을 넣을 수 있습니다. |
| 접기 | 접기 안에 접기를 넣는 구조를 지원하며, 서버에서 최대 4단계의 접기를 허용합니다. |
| 표 | 2~6열, 제목 행을 포함한 2~11행, 셀당 100자까지 입력합니다. 본문에 삽입할 위치를 고를 수 있습니다. |
| 그래프 | 제목과 항목별 숫자를 입력하는 그래프 기능을 제공합니다. 항목은 1~10개이며 서버가 수치를 검증합니다. |
| 투표 | 질문과 2~8개 항목을 만들고 본문 위치를 선택합니다. 로그인한 회원이 투표당 한 번 참여합니다. |
| 투표 기간 | 일반 회원은 15·30·45·60분, 운영 권한이 있는 회원은 1·7·15·30일도 선택할 수 있습니다. |
| 이모지 | 본문, 댓글·대댓글, 투표 질문·항목에 기본 이모지를 사용할 수 있습니다. |

### 첨부 파일

JPG·PNG·WebP·GIF와 MP4·WebM을 합쳐 최대 4개 첨부합니다. 이미지는 개당 5MiB, 영상은 개당 20MiB, 전체 첨부 합계는 24MiB 제한입니다.

이미지·GIF가 있는 글에는 목록에 첨부 표시가 붙습니다. 마우스를 사용할 수 있는 화면에서는 제목을 가리켜 미리 볼 수 있으며, 본문의 이미지는 클릭해서 확대합니다. 게시글 수정에서 첨부를 추가하거나 제거할 수 있습니다. 휴대폰에는 마우스 호버를 전제로 한 미리보기 대신 본문 열기와 이미지 확대를 이용합니다.

## 댓글, 추천과 블라인드

댓글과 대댓글은 합쳐 회원별 5초의 작성 간격을 적용합니다. 상세 화면의 작성자 표시는 프로필 사진·닉네임·레벨·뱃지로 구성하며, 채널 목록의 작성자는 간결하게 닉네임을 보여 줍니다. 사진이나 닉네임을 통해 회원 프로필을 열 수 있습니다.

게시글과 댓글에 추천·비추천을 제공하며, **게시글 자동 블라인드**는 비추천이 6개 이상이고 동시에 추천의 2배 이상인 경우 적용합니다. 조건에서 벗어나면 자동 블라인드가 해제됩니다. 운영 방침 및 법령 채널과 각 채널의 중요 공지는 이 자동 처리의 예외입니다.

담당 운영자는 별도로 게시글을 수동 블라인드하거나 댓글을 가릴 수 있습니다. 수동 블라인드와 해제에는 사유를 남기며 작성자에게 알림을 전달합니다. 일반 회원의 화면에서는 제한된 글의 원문 접근을 막고, 가려진 댓글에는 안내 문구를 표시합니다.

## 회원가입과 계정 관리

- 이메일 인증 가입과 기존 이메일의 중복 가입 방지, 아이디 찾기, 비밀번호 재설정을 제공합니다.
- 인증번호는 5분 제한이며, 재발송 간격은 1분입니다. 발송·만료 상태를 화면에서 안내합니다.
- 가입 시 연령 확인과 필수 약관·개인정보 동의 절차가 있습니다.
- 닉네임은 2~8자이며, 일반 회원의 닉네임 변경은 500P와 7일 간격을 적용합니다. 총괄운영자는 이 비용·간격의 예외입니다.
- 운영자와 혼동하기 쉬운 아이디·닉네임 문구는 가입·변경 검증에서 제한합니다.
- 프로필 사진은 본인 사진이나 변경 버튼으로 바꿀 수 있고, 변경 안내에서 1,000P 비용을 확인합니다.
- 서로 다른 디자인의 뱃지 5종을 제공하며 프로필에서 선택합니다.
- 비밀번호 변경과 회원탈퇴는 현재 비밀번호를 확인하는 별도 절차입니다.

닉네임·사진·뱃지는 회원 정보에서 관리하고 글과 댓글 조회 시 현재 정보를 연결합니다. 닉네임을 바꿀 때 과거 모든 글·댓글의 작성자 문자열을 일괄 변경하는 구조가 아닙니다.

## 프로필, 활동, 포인트

내 프로필에서는 작성한 글·댓글·저장한 글의 수를 누르면 본인의 목록을 열 수 있습니다. 타인 프로필의 글·댓글 수는 통계로 표시하며 해당 회원의 전체 작성 목록으로 연결하지 않습니다.

활동 달력은 최근 365일을 한국 시간 기준으로 보여 줍니다. 날짜를 누르면 그날의 활동 여부와 글·댓글 수를 확인합니다. 본인 화면은 서버가 관측한 최초·최종 활동 시각도 제공하며 타인에게는 접속 시각을 제공하지 않습니다. 이 값은 모든 실제 접속 순간이나 정확한 체류 시간의 로그를 뜻하지 않습니다.

계정 히스토리는 계정 생성일, 닉네임 변경, 레벨업 기록을 보여 줍니다. 포인트 내역은 적립·사용·지급·차감과 날짜를 구분합니다.

| 항목 | 기준 |
| --- | --- |
| 글 작성 | 15P 적립 |
| 댓글·대댓글 작성 | 3P 적립 |
| 레벨 | 1~100, 레벨 1→2에 100P 필요, 이후 단계별 요구량을 직전의 1.5배로 올림 |
| 보유 포인트 | 누적 적립과 운영자 지급에서 사용·차감을 계산합니다. 징계로 음수가 될 수 있습니다. |
| 포인트 차감·사용 | 보유량에 반영하며, 일반적인 사용·차감으로 누적 획득 기준 레벨이 내려가지는 않습니다. |
| 초기화 | 포인트 잔액 초기화, 레벨 초기화, 두 항목 초기화를 구분합니다. |

포인트 상점은 현재 일반 회원에게 오픈 준비 중 안내를 보여 줍니다.

## 쪽지, 회원 차단과 알림

다른 회원의 프로필에서 쪽지를 보낼 수 있습니다. 받은 쪽지와 보낸 쪽지를 구분하고, 읽지 않은 수와 쪽지 신고 기능을 제공합니다.

차단한 회원의 글과 댓글은 **차단한 사람의 화면**에서 가려지고 다른 회원에게는 그대로 보입니다. 차단당한 회원은 차단한 사람에게 쪽지를 보낼 수 없으며 해제 후 다시 보낼 수 있습니다.

사이트 안의 종 아이콘은 댓글·대댓글·쪽지·관련 안내를 표시합니다. 프로필의 쪽지함과 제재 내역에도 알림 위치를 구분합니다. Android 앱은 같은 서버 이벤트를 FCM으로 받아 앱이 닫힌 상태에서도 시스템 알림을 표시하며, 전체·글 댓글·대댓글·제재·쪽지 설정을 따로 제공합니다.

## 운영과 신고

| 직급 | 담당 범위와 주요 권한 |
| --- | --- |
| 총괄운영자 | 전체 채널·회원 관리, 운영자 지정, 전체 신고·운영 기록, 시스템 공지와 개설 승인 |
| 채널 운영자 | 담당 상위 채널과 그 세부 채널의 운영·신고, 허용된 회원 제재와 포인트 조정 |
| 세부 관리자 | 지정된 세부 채널의 신고·제한 관리, 뮤트·세부 채널 이용 제한과 해제 |

세부 관리자는 전체 계정 정지나 포인트·레벨 초기화 권한을 갖지 않습니다. 채널 운영자는 회원 이메일을 열람하거나 운영자를 지정할 수 없습니다. 운영 기록은 총괄운영자가 전체를 보고, 다른 운영자는 허용된 범위에서 본인 처리 기록을 봅니다.

신고는 상위/세부 채널로 구분하고 담당 범위에 맞게 처리합니다. 적용 조항, 처리 사유와 추가 설명, 징계를 선택할 수 있습니다. 처리 운영자와 날짜를 기록하며, 포인트·정지·초기화·권한 변경·제한 해제처럼 중요한 조작에는 대상과 내용을 보여 주는 확인 절차가 있습니다.

신고 처리 결과의 공개 글에는 신고번호, 적용 조항, 처리 결과와 요약 사유를 사용합니다. 신고 원문·원문 링크·닉네임 등 개인 식별 정보를 공개 결과 글에 그대로 복제하지 않습니다. 신고자의 프로필에는 본인이 접수한 신고의 대기·처리 완료·반려 상태를 표시합니다.

### 삭제와 기록

운영자 삭제와 신고 처리에 따른 삭제는 먼저 공개 화면에서 원문을 숨기고, 담당 권한을 가진 운영자가 운영 기록의 링크로 7일 동안 확인하게 합니다. 이후 보관 원문을 자동으로 말소합니다. 댓글 삭제 시 대댓글을 유지하는 구조도 포함합니다. 작성자가 직접 글을 삭제하는 경우는 운영자 7일 보관 절차와 다르게 즉시 삭제합니다.

계정 정지와 해제, 뮤트와 세부 채널 이용 제한, 블라인드와 해제에는 사유와 처리자를 남깁니다. 제재 내역을 초기화하는 기능은 회원에게 보이는 해당 내역과 운영 감사 기록의 보존을 구분합니다.

## 공지·광고·통계

시스템 중요 공지는 특정 작성자 계정을 삭제하더라도 유지되도록 관리합니다. 공지 묶음은 3개씩 표시하고 10초 간격의 위쪽 전환과 일시정지·재생을 제공합니다. 비공개 공지는 공개 공지 목록에서도 권한에 맞게 제외합니다.

PC의 양쪽 4개 광고 자리는 모바일 앱에서 상단 2개와 하단 2개 배너로 배치합니다. 광고·제휴 문의는 별도 안내·접수 화면과 총괄운영자 전용 조회·삭제 기능을 제공합니다. 임시 배너 표시와 외부 광고 플랫폼 심사·승인은 서로 다른 상태입니다.

하단에는 현재 접속 브라우저 수, 누적 방문 브라우저 수와 이용약관·개인정보처리방침·청소년보호 정책·광고 문의 링크를 정렬합니다. 현재 접속자는 최근 5분 관측 기준이고, 같은 브라우저의 쿠키가 유지되는 동안 여러 탭이나 새로고침을 누적 방문자로 반복 계산하지 않습니다.
