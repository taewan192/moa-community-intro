# 인증·권한·데이터 수명과 검증

[소개](../README.md) · [DB 구조](database.md) · [개발·운영](development-and-operations.md)

## 1. 계정 인증

비밀번호는 회원마다 salt를 사용하는 scrypt 해시로 보관합니다. 로그인 후에는 쿠키 기반 서버 세션을 사용하며, DB에는 세션 토큰 원문 대신 해시·만료·회원 연결 정보를 보관합니다. 현재 세션 유효기간은 7일입니다.

가입 이메일의 중복을 검사하고 이메일 인증 후 계정을 생성합니다. 아이디 찾기와 비밀번호 재설정도 인증번호로 본인 이메일 접근을 확인합니다. 코드는 5분 만료, 재발송은 1분 간격이며 시도·요청 제한을 함께 적용합니다. 발송 실패와 화면의 성공 안내를 구분하는 것이 중요합니다.

로그인·가입 메일 발송·아이디 찾기·비밀번호 재설정의 주요 인증 요청은 Turnstile을 적용합니다. 서버가 토큰, 허용 호스트와 작업 종류를 확인하므로 화면의 체크 표시만 신뢰하지 않습니다.

## 2. 서버가 확인하는 권한

클라이언트가 버튼을 숨기는 것은 사용자 경험을 위한 것입니다. 실제 변경 권한은 서버가 다시 검사합니다.

| 요청 | 서버 검사 예 |
| --- | --- |
| 본인 글·댓글 수정 | 로그인 회원과 작성자 연결 |
| 쪽지 읽기 | 발신·수신 소유권 |
| 쪽지 보내기 | 차단 관계와 발신 제한 |
| 글·댓글 작성 | 계정 정지, 세부 채널 정지·뮤트, 작성 간격 |
| 운영 API | 총괄/채널/세부 권한과 담당 채널 |
| 블라인드 원문·삭제 보관 원문 | 공개 상태, 운영 권한, 보관 기한 |
| 앱 기기 등록 | 세션의 실제 회원과 등록 대상, 기기 인증·변경 순서 |

변경 요청의 Origin도 확인합니다. 프록시 환경의 실제 방문자 IP를 구분해 요청 횟수를 제한하며, 임의 헤더가 언제나 신뢰할 수 있다고 가정하지 않습니다. Cloudflare의 프록시·웹 방화벽과 애플리케이션 권한 검사는 서로 다른 계층입니다.

## 3. 입력과 첨부

본문 서식을 허용 목록과 구조화된 데이터로 검증합니다. 글자 크기·링크 프로토콜·접기 깊이·표 셀·투표 항목과 그래프 수치를 제한합니다. 임의 JavaScript나 임의 HTML 실행을 게시글 기능으로 제공하는 방식은 아닙니다.

첨부는 허용 MIME/파일 형식, 실제 파일 특징과 개수·용량을 확인합니다. 회원이 올린 이미지·영상과 프로필 사진은 미디어 응답 경로를 통해 제공합니다. 이 설명은 악성 파일에 대한 모든 상황의 안전성을 보증하는 보안 감사 결과는 아닙니다.

## 4. 개인정보와 공개 범위

다른 회원 프로필에는 공개 닉네임·사진·레벨·배지·포인트·활동 통계를 표시합니다. 본인 활동의 최초/최종 관측 시각과 본인의 전체 작성 목록은 타인 공개 화면에서 제외합니다. 이메일 열람은 일반 채널 운영자·세부 관리자에게 제공하지 않습니다.

푸시에는 필요한 종류·이벤트·이동 정보만 담고 쪽지 본문·회원 이메일·징계 자유 입력 사유를 그대로 복제하지 않습니다. 알림을 눌러 실제 내용을 볼 때도 서버 세션과 권한을 확인합니다.

클라이언트 Firebase API 키·프로젝트 식별자와 FCM 발송 개인키는 용도가 다릅니다. **서버 발송 개인키, SMTP 비밀번호, Turnstile Secret, 앱 서명키는 공개 문서와 APK에 포함하지 않습니다.**

## 5. 보관과 삭제의 구분

| 자료 | 현재 처리 |
| --- | --- |
| 운영자 삭제 글·댓글 원문 | 공개에서 제외하고 담당 권한으로 7일 확인, 이후 원문 말소 |
| 본인 직접 게시글 삭제 | 운영자 7일 보관 절차와 구분해 즉시 삭제 |
| 계정 탈퇴 | 로그인 차단·익명화와 계정 관련 개인 설정 정리, 남는 글·댓글은 탈퇴 회원 표시 |
| 회원에게 보이는 제재 내역 | 초기화 가능, 운영 감사 기록과 분리 |
| 계정 히스토리 | 생성·변경·레벨 사건별 기록 |
| 활동 달력 | 최근 365일, 한국 시간 기준 날짜 |
| 광고·제휴 문의 | 코드상 90일 보관 정리 및 총괄 삭제 기능 |
| 푸시 대기열 | 오래된 기록은 2일 기준 정리, 1시간이 지난 사건은 발송 제외 |

표는 애플리케이션 동작을 설명합니다. '탈퇴하면 모든 게시물·감사 자료·백업까지 즉시 물리 삭제'나 '모든 데이터가 90일 안에 자동 삭제'를 뜻하지 않습니다. 서비스가 공개한 정책과 실제 운영 보관 절차는 별도로 함께 확인해야 합니다.
